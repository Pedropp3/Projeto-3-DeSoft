# Projeto-3-DeSoft

Copa futebol

Pedro, Nicolas e Eduardo

Para iniciar o jogo, basta escolher o jogador, utilizando as setinhas do teclado, clicar "Espaco" para ir para a proxima tela quando na tela de chaves. Seta esquerda e Seta direitapara movimentacao do personagem e Espaco para pular. Apos fazer 3 gols, voce avanca para a proxima etapa, mas se levar 3 gols, voce perde.

IA utilizada em:
movimento do oponente, a escolha do adversario, menu abrir e ajustar o som, deixar as animacoes fluidas, criar imagem de vitoria e derrota, deixar o codigo organizado no ultimo commit, criar delays, chute (hitbox). Copilot utilizado 4%
